# Galaxium

Galaxium is an AI-powered Roblox Studio plugin that helps you build and script Roblox games faster.

## Features

- AI scripting
- Luau help
- Roblox development assistance
- Script debugging

## CDN

Production static chunks and public assets use `https://galaxium-cdn.troojin.com`.
Point that Cloudflare hostname at the deployed app and cache `/_next/static/*`,
`/cdn/*`, and `/icons/*`. Set `CDN_URL` and `NEXT_PUBLIC_CDN_URL` together if
the hostname changes.
